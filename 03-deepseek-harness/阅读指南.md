## 1. 项目定位

DeepSeek 官方开源的 **agent harness（智能体框架）**，代号 `dsh`。核心设计是 **"一切皆插件"（Everything is a Plugin）**：构建在 [Cordis](https://github.com/cordiverse/cordis) 框架之上，模型适配器、工具注册表、会话日志、**乃至 agent loop 本身**都是插件，全部可从配置替换；**不存在需要打补丁的特权内核**（`docs/architecture.zh.md`）。

与另两家的定位差异（一句话）：Claude Code / Codex 是"官方 IDE 级成品 CLI"，dsh 是"**可组装的 agent 平台**"——同一套内核通过不同 profile（web / headless / sdk / acp / desktop）装配成 Web 应用、桌面应用、SDK 服务或自动化服务；甚至内置了把 **Claude Code、Codex 当作子代理**调用的适配器（`packages/subagent/subagent-claude-code`、`subagent-codex`）。

安全提示：运行前务必读 `SAFETY.zh.md`——实验性软件、未经过安全审计、会执行模型生成的代码，官方建议只在一次性 VM/容器中试用。

## 5. 本地运行

```sh
# 最快体验（发布包）
npx @deepseek-ai/dsh web        # Web UI: http://127.0.0.1:3080（--no-open 可不自动开浏览器）

# 从源码
pnpm install
pnpm run build
pnpm dsh web
```

环境：Node `^22.19.0 || >=24.0.0`，pnpm 11（`packageManager: pnpm@11.7.0`）。其他入口（`apps/cli/README.zh.md`）：

- `dsh --profile headless "任务"`：跑一次持久会话，打印最终答案退出。
- `dsh --profile sdk` / `sdk-minimal`：JSON-RPC stdio，供 SDK（Python/TS）调用。
- `dsh --profile acp`：ACP stdio，供自动化客户端。
- `dsh plugin --profile web <pnpm args>`：管理该 profile 的插件。
- `dsh --profile web --dump-config`：打印最终插件配置树（理解 patch 分层的利器）。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| **dsh** | DeepSeek Harness 的代号/命令名 |
| **Cordis** | 底层插件框架：插件向共享 `ctx` 贡献服务、类型化事件与**可逆**副作用；卸载即撤销注册 |
| **ctx（上下文）** | Cordis 的服务容器；核心键：`ctx.agents`、`ctx.agentLoop`、`ctx.sessions`、`ctx.systemPrompt`、`ctx.tools`、`ctx.llm` |
| **profile** | 存放在 `$DSH_HOME/profiles/<name>` 的命名装配：列出组合包 + 自己的 `cordis.patch.yml`；内置 `web`/`headless`/`sdk`/`sdk-minimal`/`acp` |
| **组合包（bundle）** | 可分发的一层 Cordis 配置 + 挂载代码；通过 package.json 的 `dsh.bundle` 声明 |
| **patch** | 按 id 定位配置条目并替换其 config（或插入新条目）；层次：bundle → profile patch → home patch → `--patch` |
| **轮次 turn / 步骤 step** | 轮次在领取首条输入时打开、无欠账时关闭；步骤 = 一次模型请求 + 它调用的工具 |
| **会话事件 / agent 事件** | 会话事件是持久事实（追加到日志、`session/event` 广播）；`agent/*` 是实时扩展点（inbox、步骤、状态等） |
| **waterfall 事件** | 监听器必须调用 `next()` 才能委托下去的事件（如 `agent/pre-step`、`agent/request`、`llm/stream`、`tools/*`） |
| **seam（能力缝）** | 可替换能力的三元组：Service Definition / Provider / Consumer；换 provider 即换产品形态（如 FS 指向远程沙箱，Bash/PTY/LSP 一起搬过去） |
| **assistant-stream** | 进程本地的流式帧（start/chunk*/end）；settlement 时提交为 `assistant/message`（成功）或 `assistant/attempt`（失败/重试/取消） |
| **session 日志** | 模型上下文的唯一真源，`deriveMessages()` 从中投影模型历史；"模型可见即已记录"是运行时不变量 |
| **session projection** | `ctx.sessionProjections`：增量折叠已提交事件得到类型化状态（`stateOf()`）与客户端裁剪视图（`snapshot()`） |
| **compaction** | 上下文压缩：`dsh-compaction-basic` 通过 `agent/pre-step` 处理压力、先剪枝工具结果再摘要；溢出走 `agent/request-error` |
| **spill** | 大工具输出外溢到存储（`packages/spill`）而不是塞满上下文 |
| **subagent provider** | 子代理提供方接口；实现包括新建子 agent、fork、或把轮次委派给 Claude Code/Codex 等其他产品 |
| **preset（agent 预设）** | 一个会话的能力集合装配（哪些工具/服务以 isolate realm 挂载） |
| **ACP** | Agent Client Protocol，编辑器/自动化客户端接入标准 |
| **guard** | 保护性策略（重复工具调用提醒、超时策略等） |
| **typert** | 类型化运行时契约生成体系（generator/loader/registry/protocol） |
