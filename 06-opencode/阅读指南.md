## 1. 项目定位

OpenCode 是"**HTTP-first 的多前端 coding agent**"：内核是一个 Effect 写的 server（会话、工具、权限、provider 全在服务端），TUI / Web / Electron / VS Code / ACP / GitHub Action 都只是它的 HTTP 客户端。规范甚至把这个边界写死：`specs/tui-package.md:22-30` 规定 TUI **不得**依赖 `packages/opencode`，只能通过 SDK 通信。

与另五家的定位差异（一句话）：

- Claude Code / ZCode 是"CLI/TUI 单体内核 + 前端"，OpenCode 把自家 CLI 降级成普通 HTTP client；
- Codex 用 Rust + app-server 守护进程，OpenCode 用 TS + **Bun Worker 线程**（默认不占端口，`fetch` 被桥成进程内直调）；
- DeepSeek Harness 靠 Cordis 插件树装配，OpenCode 靠 Effect 的 `Layer` / `Context.Service` + npm 插件；
- OpenClaw 是"接进真实通讯渠道、真的去干活"的助理，OpenCode 仍是坐在工作机上的编码 agent。

⚠️ 安全：**没有 OS 级沙箱**（详见架构拆解第 6 节）。`--yolo` / `--dangerously-skip-permissions` 一键放开全部权限，日常防线只有权限规则 + 弹窗。另：`share` 走 opencode.ai 云，**链接 + secret 即可读**完整会话（含工具输出与文件内容），关掉要用 `OPENCODE_DISABLE_SHARE` 或 `config.share:"disabled"`。

## 6. 本地运行

```bash
# 环境：Bun（CONTRIBUTING.md:34 要求 1.3+，仓库锁 bun@1.3.14）
bun install
bun dev                     # 起交互式 TUI = 服务端跑在本进程 Worker 线程
bun dev <dir>               # 指定项目目录
bun dev serve --port 8080   # headless HTTP API（默认端口 4096）
bun dev web                 # server + 打开 Web UI
bun run dev:web             # packages/app（Vite，5173），需先起 serve
bun run dev:desktop         # packages/desktop（Electron）
bun run dev:console         # Cloudflare/SaaS 站点（packages/console/app）

# 验证：测试与 typecheck 必须在包目录里跑
bun run --cwd packages/opencode test
bun run --cwd packages/opencode typecheck   # = tsgo --noEmit
bun lint                                    # oxlint

# 构建本机单二进制
bun run --cwd packages/opencode build
# 产物：packages/opencode/dist/opencode-<platform>-<arch>/bin/opencode
```

三个必须知道的坑：

1. **测试不能从仓库根目录跑**：`bunfig.toml:11-12` 把 root 指向不存在的 `./do-not-run-tests-from-root`，根 `package.json:23` 的 test 脚本直接 `exit 1`（`AGENTS.md` 也写了这条护栏）。
2. **断点打不进服务端**：默认服务端在 Worker 线程里，调试要用 `bun dev spawn`（拆成真进程）或 `bun run --inspect=ws://… ./src/index.ts serve --port 4096` + `opencode attach http://localhost:4096`（`CONTRIBUTING.md:145-157`）。
3. **改了协议/HTTP API 要重生成 SDK**：`bun run generate`（`script/generate.ts:5-7` 把 server 的 OpenAPI 导出到 `packages/sdk/openapi.json`），不要手改 `packages/client/src/generated*`。

TUI 支持 `SIGUSR2` 热重载（`tui.ts:216-218` → `worker.ts:63-71`：失效 config、dispose 所有 instance）。

## 7. 术语表

| 术语 | 含义 |
|---|---|
| **V1 / V2 内核** | V1 = `packages/opencode/src/session/*`（当前生产主路径）；V2 = `packages/core/src/session/*` + `CONTEXT.md` 那套 durable admission 语义，两者并存、靠 bridge 缝合 |
| **Admitted Prompt** | 已入队但未必已进入模型历史的用户输入；落 `session_input` 表（`core/src/session/sql.ts:140`） |
| **Prompt Promotion** | 序列化 runner 在"安全的 provider-turn 边界"把 admitted 输入提升为可见 user 消息 |
| **Session Drain** | 一次排空可投递输入的本地执行过程；drain **没有**持久身份、也不构成 transcript 边界 |
| **Context Epoch** | 上下文代际，持久化在 `session_context_epoch`（`sql.ts:168`） |
| **System Context / Context Source** | 系统上下文的代数结构与其生产者（`core/src/system-context`） |
| **Rule / Ruleset** | 权限最小单元 `{permission, pattern, action: allow\|deny\|ask}`；多条拼成 Ruleset（`schema/src/v1/permission.ts:20-26`） |
| **findLast 求值** | 所有 ruleset 拍平后取**最后一条**双通配匹配的规则 ⇒ 后写覆盖先写；无匹配默认 `ask` |
| **Reply** | 用户对审批的三种回答：`once` / `always` / `reject` |
| **arity 字典** | `permission/arity.ts` 的命令归一化表：把 `npm run dev xxx` 折成 `npm run dev` 这种可匹配 pattern，配合 tree-sitter 实解析 |
| **doom loop** | 最近 3 个 part 是"同工具 + 同参数" ⇒ 触发 `doom_loop` 审批（`processor.ts:353-380`） |
| **overflow / usable** | `usable = limit − reserved`（默认 `min(20000, maxOutputTokens)`）；`count >= usable` 即判定溢出（`overflow.ts:10-34`） |
| **compaction** | 摘要压缩：head 交给内建 `compaction` agent 生成摘要，tail 逐字保留（`preserve_recent_tokens = clamp(usable×0.25, 2k, 15k)`） |
| **prune** | 与 compaction 独立的**可选**开关（默认关）：把 40k token 之外的老工具输出替换成 `[Old tool result content cleared]` |
| **ProcessorResult** | 处理器返回 `"compact" \| "stop" \| "continue"` 三态，`runLoop` 据此决定退出（`processor.ts:30,693-695`） |
| **models.dev** | provider/模型目录的外置部署（`models.opencode.ai`），加新 provider 主要靠给它提 PR 而非改本仓 |
| **LLMEvent** | 双引擎（Vercel AI SDK / 自研 native）统一后的流式事件词汇表 |
| **codemode** | `packages/codemode`：受限解释器，让模型用脚本连续调用被 schema 描述的 MCP 工具，减少往返 |
| **Snapshot** | 用独立 `--git-dir` + `--work-tree` 的内容寻址存储，使非 git 目录也能 revert/undo（`snapshot/index.ts:71-75`） |
| **share** | 会话上云分享：URL + secret 即读，事件批量 flush 到 opencode.ai |
| **ACP** | Agent Client Protocol，`opencode acp` 起 stdio 服务端供编辑器接入 |
| **`#db` imports** | `packages/opencode/package.json:25-29` 声明的运行时条件导入（bun / node 各一个驱动文件）。⚠️ **该映射的目标文件 `src/storage/db.bun.ts`、`db.node.ts` 在检出树里并不存在，且无源码引用**——迁移遗留，按 `packages/core/src/database/database.ts:45-54` 找真正的库路径逻辑 |
| **lildax** | `packages/cli` 的 bin 名（另一个入口，非主线） |
