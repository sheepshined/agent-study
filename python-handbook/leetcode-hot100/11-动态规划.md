## 70. 爬楼梯

> [难度：简单] ｜ [LeetCode 链接](https://leetcode.cn/problems/climbing-stairs/) ｜ 标签：数学 · 动态规划 · 记忆化搜索

### ① 题意速览
你正在爬楼梯，每次可以爬 1 或 2 个台阶，问到达第 n 阶有多少种**不同的走法**。
- 示例：n = 3 → 3（1+1+1 / 1+2 / 2+1）
- 关键约束：1 ≤ n ≤ 45；1+2 与 2+1 算两种不同走法。

### ② 思路讲解
**从暴力出发**：递归枚举每一步"走 1 还是走 2"：f(n) = f(n−1) + f(n−2)。直接递归是指数级的——递归树有 O(2ⁿ) 个节点，而其中**不同的子问题只有 n 个**：算 f(5) 要 f(4) 和 f(3)，算 f(4) 又要 f(3)……"同一个小问题被反复计算"，这叫**重叠子问题**（Overlapping Subproblems，DP 存在的第一理由）。

**状态定义（说人话）**：dp[i] = 走到第 i 阶的方法总数。**转移方程**：最后一步只有两种来路——从第 i−1 阶跨 1 步、或从第 i−2 阶跨 2 步，两类互不重叠又穷尽所有走法，所以 dp[i] = dp[i−1] + dp[i−2]。**初始化**：dp[1] = 1、dp[2] = 2（若增设 dp[0] = 1 表示"站在原地算一种"，递推可统一从 i = 2 开始）。**遍历顺序**：i 从小到大——当前状态只依赖更小的下标，顺着填表即就绪。

**滚动三变量**：dp[i] 只依赖前两项，用两个变量滚动即可把空间压到 O(1)。这个递推正是**斐波那契**（Fibonacci，斐波那契数列）——爬楼梯就是"给斐波那契一个物理意义"。

**不变量（Invariant，循环每一步都保持为真的性质）**：滚动推进到第 i 轮结束时，`prev` 与 `cur` 恰好等于 dp[i−1] 与 dp[i]。有了它，任意 n 的返回值由归纳保证。

**追问·加约束"不能连续走两步"**：原来的 dp[i] 不够用了——转移要禁止"2 接 2"，但 dp[i] 里看不出"最后一步走了几"。**状态拆分**：a[i] = 最后一步走 1 到达 i 的方案数，b[i] = 最后一步走 2 到达 i 的方案数；则 a[i] = a[i−1] + b[i−1]（走 1 随便接），b[i] = a[i−2]（走 2 要求到 i−2 时最后一步不是 2）。**当转移需要"上一手"信息而状态里没有时，给状态加一维**——这是 DP 的通用扩张手段（买卖股票含冷冻期、带障碍路径同款操作）。

**套路迁移**："计数 DP"的原型：状态 = 前缀处的计数，转移 = 对"最后一步"分类。同家族：不同路径（62 题，二维版）、解码方法（LC 91，数字串拆法计数，带 0 的特判陷阱）。

### ③ 注释代码
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # 状态：dp[i] = 到第 i 阶的方法数；转移：dp[i] = dp[i-1] + dp[i-2]
        # dp[i] 只依赖前两项 -> 滚动变量，O(1) 空间
        prev, cur = 1, 1      # prev = dp[0]（原地记 1 种），cur = dp[1]
        for _ in range(n - 1):
            # 不变量：滚动一轮后 prev, cur 依次前移为 dp[i-1], dp[i]
            prev, cur = cur, prev + cur
        return cur
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(n)**：一遍递推；**空间 O(1)**：滚动变量。
- **易错点**：
  1. 裸递归（不记忆化）是 O(2ⁿ)，n = 45 直接超时——本题是"暴力递归 → 记忆化 → 递推"教学链的起点；
  2. 滚动初值要让 n = 1、n = 2 都正确：`prev, cur = 1, 1` 配 `n−1` 轮循环，初值错一个小 n 就崩；
  3. 别把"1+2 与 2+1"合并成一种：按"最后一步"分类天然区分顺序，dp 不会漏也不会重。
- **面试追问**：
  1. 相邻两步不能都走 2 怎么办？→ 状态拆成"最后一步是 1 / 是 2"两支（见②追问）；
  2. 每步可以走 1~m 阶呢？→ dp[i] = Σ dp[i−k]（k=1..m），内层求和用前缀和摊平到 O(n)。

## 118. 杨辉三角

> [难度：简单] ｜ [LeetCode 链接](https://leetcode.cn/problems/pascals-triangle/) ｜ 标签：数组 · 动态规划

### ① 题意速览
给定行数 numRows，生成杨辉三角的前 numRows 行：每行首尾是 1，中间每个数等于上一行相邻两数之和。
- 示例：numRows = 5 → `[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`
- 关键约束：1 ≤ numRows ≤ 30。

### ② 思路讲解
**为什么说它是最朴素的二维 DP 训练**：杨辉三角本身就是一张 DP 表——第 i 行第 j 个数就是"状态"，它由**上一行的两个子状态**拼出来。状态定义（说人话）：f(i, j) = 三角中 (i, j) 位置的数值；再换一层含义：f(i, j) = 从顶点每步"左下/右下"走到 (i, j) 的路径条数——这层"路径计数"视角与 62 不同路径完全同构，只是地图从矩形换成三角形。

**转移方程**：row[j] = 上一行的 j−1 与 j 之和（中间位置）；每行首尾恒为 1（边界状态："走到边上只有一条路"）。**初始化与遍历顺序**：从第 0 行 `[1]` 起逐行向下构造；实现上每行先开全 1，再只填中间段 `j ∈ [1, i−1]`——首尾的边界值天然就位。

**不变量**：构造第 i 行时，第 i−1 行已完整就绪；每个格子的两个依赖都在"上一行"，逐行从上往下填恰好满足依赖方向——**"填表时依赖的格子一定已填好"是一切递推 DP 的正确性底线**。

**一维滚动变体**：若题目只要第 N 行（LC 119），一维数组**从右往左**更新 `row[j] += row[j-1]`：倒序保证读到的是上一行的旧值——这个"倒序防覆盖"与 416 分割等和子集的 01 背包倒序是同一个机制。

**套路迁移**：二维 DP 的入门原型：状态二维下标、转移来自上一行。往深走全是它的放大版：62/64（网格路径）、1143/72（双字符串游标）。**看到"每个位置由上方/左方决定"，就是这张表换了皮肤**。

### ③ 注释代码
```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        res = []
        for i in range(numRows):
            row = [1] * (i + 1)          # 首尾本就是 1，先全部置 1
            for j in range(1, i):        # 只填中间：row[j] = 上一行 j-1 + j
                row[j] = res[i - 1][j - 1] + res[i - 1][j]
            # 不变量：第 i-1 行已完整，本行中间段由它拼出
            res.append(row)
        return res
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(numRows²)**：表本身就这么多格子；**空间 O(1)**（不计返回的表，它占 O(numRows²)）。
- **易错点**：
  1. 内层循环是 `range(1, i)`——j 最大到 i−1，首尾不动；写成 `range(i + 1)` 会访问 `res[i-1][i]` 越界；
  2. 第 0、1 行没有中间段，靠空循环天然跳过，不必特判；
  3. `row = [1] * (i + 1)` 之后不要再 append——长度会失控。
- **面试追问**：
  1. 只要第 k 行且 O(k) 空间？→ 一维数组从右往左 `row[j] += row[j-1]`（LC 119）；
  2. 杨辉三角和组合数什么关系？→ f(i, j) = C(i, j)，逐行递推就是"用加法算组合数"——62 题追问的组合公式会再用到它。

## 198. 打家劫舍

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/house-robber/) ｜ 标签：数组 · 动态规划

### ① 题意速览
一排房子各有现金 `nums[i]`，**不能偷相邻两家**，求能偷到的最大金额。
- 示例：`[2,7,9,3,1]` → 12（偷 2 + 9 + 1）
- 关键约束：房屋排成一条直线；金额非负。

### ② 思路讲解
**从暴力出发**：每家"偷/不偷"两种决策，2ⁿ 种组合里过滤掉相邻冲突——指数级。**贪心也不行**："谁钱多偷谁"会翻车：`[2,7,9,3,1]` 里贪 7 就挡住了 9，亏 2。局部最优换不来全局最优——这种"决策互相影响"的最优化请直接上 DP。

**状态定义（说人话）**：f(i) = **只考虑前 i+1 家**（下标 0..i）能偷到的最大金额。注意它说的是"考虑到第 i 家"，**不**代表"必须偷第 i 家"——这是本题最容易想岔的地方。

**转移方程与两个来源**：对第 i 家只有两种决策，覆盖全部可能：
1. **不偷第 i 家**：收益 = 前 i−1 家的答案 f(i−1)；
2. **偷第 i 家**：第 i−1 家必须空着，收益 = f(i−2) + nums[i]。
取大：f(i) = max(f(i−1), f(i−2) + nums[i])。**为什么"不偷 i"不用再讨论 i−1 偷没偷**：f(i−1) 的定义本身已是"前 i−1 家的全局最优"，无论其方案细节如何都是合法上界且可达——**状态定义写得干净，转移就无需补丁**。

**初始化与遍历顺序**：f(0) = nums[0]、f(1) = max(nums[0], nums[1])，i 从 2 递增；实现上设虚拟的 f(−1) = f(−2) = 0 从头推更顺。dp[i] 只依赖前两项 → 滚动两个变量，O(1) 空间。

**不变量**：计算 f(i) 时，f(i−1) 与 f(i−2) 分别是"前 i−1 家 / 前 i−2 家"的全局最优——大问题的最优由子问题的最优拼出，这就是**最优子结构**（Optimal Substructure，DP 正确性的根基）。

**追问·环形版（LC 213 打家劫舍 II）**：房子围成一圈、首尾相邻。环形问题的标准拆法是**拆成两次线性**：方案 A 不偷第 0 家 → 对下标 1..n−1 跑本题；方案 B 不偷第 n−1 家 → 对 0..n−2 跑本题；取大。"首尾至少空一家"的两分类恰好穷尽所有合法方案，环形约束被翻译成两个无环子问题。

**套路迁移**："逐家做选/不选决策 + 相邻约束"的决策 DP 原型。同家族：打家劫舍 III（LC 337，决策挂到树节点上做树形 DP）、买卖股票系列（状态机 DP）。口诀：**当前决策只依赖"上一个状态"→ 滚动变量；还依赖"上一手是什么"→ 状态加一维**。

### ③ 注释代码
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        # f(i) = max(f(i-1), f(i-2) + nums[i])
        # prev2 = f(i-2), prev1 = f(i-1)，滚动推进；虚拟 f(-1) = f(-2) = 0
        prev2, prev1 = 0, 0
        for x in nums:
            # 不变量：进入本轮时 prev1 是"已有前缀"的最优
            # 不偷 x -> 维持 prev1；偷 x -> 前前家最优 + x
            prev2, prev1 = prev1, max(prev1, prev2 + x)
        return prev1
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(n)**：一遍扫描；**空间 O(1)**：滚动变量。
- **易错点**：
  1. 状态若改成"必须偷第 i 家的最大收益"，转移也要跟着改为 f(i) = max(f(i−1), f(i−2)) + nums[i] 且答案取全程 max——两种定义都行，但别混用；
  2. 滚动更新必须一行完成 `prev2, prev1 = prev1, max(...)`（右值先整体求值）；拆成两行会把旧 prev1 覆盖掉；
  3. 单家 `[5]`、两家 `[5,1]` 的小规模要过：从虚拟 f(−1)=0 起步的滚动版天然兼容。
- **面试追问**：
  1. 环形怎么办？→ 拆两次线性：不偷首 / 不偷尾，各跑一遍本题取大（LC 213）；
  2. 房子是二叉树（LC 337）？→ 树形 DP：每个节点返回（偷，不偷）两个值，后序遍历自底向上拼。

## 279. 完全平方数

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/perfect-squares/) ｜ 标签：广度优先搜索 · 数学 · 动态规划

### ① 题意速览
给定正整数 n，求最少用几个**完全平方数**（1, 4, 9, 16, …）相加凑出 n（平方数可以重复使用）。
- 示例：n = 12 → 3（4 + 4 + 4）；n = 13 → 2（4 + 9）
- 关键约束：1 ≤ n ≤ 10⁴。

### ② 思路讲解
**从贪心出发看它为什么不行**：每次减去不超过剩余值的最大平方数？n = 12：12−9=3 → 3−1=1 → 1−1=0，用了 4 个；但最优是 4+4+4 共 3 个。贪心翻车的原因：拿走 9 把"剩下的 3 很难凑"这个代价甩给了后面——**每步选择会改变后续选项的价值时，贪心失效，改用 DP**。

**识别背包**：n 是背包**容量**，每个平方数是一件体积为自身、**可无限次使用**的物品——这就是**完全背包**（Unbounded Knapsack，物品无限供应的背包）求"最少件数"的版本。279 / 322 / 139 三题共用这一副骨架。

**状态定义（说人话）**：dp[j] = 凑出和恰好为 j 的最少平方数个数。**转移方程**：盯"最后用掉的那件平方数 sq"，它用掉后剩下 j−sq 是同款小问题：dp[j] = min(dp[j − sq] + 1)，sq 取所有 ≤ j 的平方数。**初始化**：dp[0] = 0（凑 0 用 0 件），其余置 INF（"尚未凑出"），防止未达状态以错误的 0 混进 min。**遍历顺序**：容量外层从小到大、平方数内层均可——求"最少件数"时内外循环次序不影响正确性（与"求组合数"形成鲜明对比，见 322 追问）。

**INF 怎么工作**：dp[j−sq] = INF 表示"j−sq 凑不出来"，INF + 1 不会小于任何可达值，min 自动忽略——INF 是"不可达"的代数化身。（本题平方数里有 1，任何 j 都可达，但初始化纪律不能因题而废。）

**不变量**：算 dp[j] 时，dp[0..j−1] 均已是各自的最优值。

**复杂度对比**：DP 为 O(n√n)（平方数只有 √n 个），空间 O(n)；另有**四平方定理**（答案 ≤ 4）配合"是否完全平方数"的判定可做到近 O(√n)——面试提一句显功底，DP 是通用主力。

**套路迁移**：完全背包"最少件数"模板：**"凑出 X 的最少件数" → dp[j] = min(dp[j − 件] + 1)**。同模子：322 零钱兑换（换成硬币）、139 单词拆分（换成"字典词"，且问的是可行性）。

### ③ 注释代码
```python
from math import isqrt

class Solution:
    def numSquares(self, n: int) -> int:
        INF = float('inf')
        dp = [0] + [INF] * n      # dp[0] = 0：凑 0 用 0 件；其余 INF = 尚未凑出
        for j in range(1, n + 1):          # 外层：容量（要凑的和）
            # 不变量：dp[0..j-1] 均已是各自最优
            for k in range(1, isqrt(j) + 1):    # 内层：枚举最后使用的平方数 k*k
                dp[j] = min(dp[j], dp[j - k * k] + 1)
        return dp[n]
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(n√n)**（√n 个平方数 × n 个容量）；**空间 O(n)**。
- **易错点**：
  1. 初始化两件套缺一不可：dp[0] = 0 是递推种子，其余 INF 是"不可达"标记——漏了后者，未达状态会以 0 污染 min；
  2. 内层上界用 `k * k <= j`（即 `isqrt(j)`）：漏枚举大平方数答案会偏大；
  3. 贪心（每次减最大平方数）是错的：n = 12 是标准反例（见②）。
- **面试追问**：
  1. 有更快的解法吗？→ 四平方定理保证答案 ≤ 4，按 1 → 4 → 2 → 3 的顺序判定可到近 O(√n)；
  2. BFS 视角怎么做？→ 0..n 建图，每个数向 x + sq 连边，0 到 n 的最短路层数即答案——"最短路 = 分阶段最优化"，与 DP 同源同复杂度。

## 322. 零钱兑换

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/coin-change/) ｜ 标签：广度优先搜索 · 数组 · 动态规划

### ① 题意速览
给定不同面额的硬币数组 `coins` 和总金额 amount，每种硬币数量无限，求凑成总金额的**最少硬币个数**，凑不出返回 −1。
- 示例：`coins = [1,2,5]`，amount = 11 → 3（5 + 5 + 1）
- 关键约束：0 ≤ amount ≤ 10⁴；coins 不含 0；amount = 0 时答案为 0。

### ② 思路讲解
**与 279 完全同型**：金额是**背包容量**、硬币是**可无限使用的物品**、求"最少件数"——把 279 的"平方数"换成"硬币面额"即可。先看贪心为什么不行：`coins = [1,3,4]`、amount = 6，贪心先拿 4 → 4+1+1 共 3 枚，而 3+3 只要 2 枚——面额之间没有贪心结构，DP 保真。

**状态定义（说人话）**：dp[j] = 凑出金额 j 的最少硬币数。**转移方程**：dp[j] = min(dp[j − coin] + 1)，coin 取所有 ≤ j 的面额。**初始化**：dp[0] = 0，其余 INF。**遍历顺序**：j 从小到大；求最值时硬币 / 金额谁在外层都正确。

**INF = amount + 1 的巧思**：不用浮点 `float('inf')`，取整数 **amount + 1** 当 INF——合法答案至多 amount 枚（全用 1 元），所以 amount+1 起到"无穷大"的作用，且全程整数运算；结尾 `dp[amount] > amount` 即"凑不出"。这类**哨兵值**（Sentinel，用一个"安全到不可能合法"的值顶替边界特判）在 DP 里随处可见。

**追问一·求方案数（LC 518 零钱兑换 II）**：min 换累加：dp[j] = Σ dp[j − coin]。此时**循环次序从无关变得致命**：
- **硬币在外层、金额在内层** → **组合数**：每枚面额"一次拿完"，{1,5} 与 {5,1} 只算一种；
- **金额在外层、硬币在内层** → **排列数**：1+5 与 5+1 算两种（LC 377 组合总和 IV 要的是这个）。
口诀：**求组合，物品在外；求排列，容量在外**。

**追问二·输出具体用了哪些硬币**：DP 只产出最优值，输出方案靠**转移时记"我从哪来"**：取 min 时顺手记 choice[j] = coin，最后从 amount 不断 `j -= choice[j]` 回溯到 0，倒序即硬币清单。这是"DP 输出方案"的通用手法（300 题、1143 题的方案输出同款）。

**套路迁移**：完全背包三兄弟——**最少件数**（本题）、**方案数**（LC 518）、**可行性**（139 单词拆分）；下一站 416 换成 01 背包（每件一次）。判型关键词：**"无限使用" → 完全背包正序；"每件一次" → 01 背包倒序**。

### ③ 注释代码
```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        INF = amount + 1            # 哨兵：合法答案至多 amount（全用 1 元）
        dp = [0] + [INF] * amount   # dp[0] = 0：凑 0 元用 0 枚
        for j in range(1, amount + 1):      # 外层：金额（背包容量）
            for coin in coins:              # 内层：最后用掉的那枚硬币
                # 不变量：dp[j-coin] 已是金额 j-coin 的最优
                if coin <= j and dp[j - coin] + 1 < dp[j]:
                    dp[j] = dp[j - coin] + 1
        return dp[amount] if dp[amount] <= amount else -1
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(amount × len(coins))**；**空间 O(amount)**。
- **易错点**：
  1. `coin <= j` 别漏：Python 负下标不报错，`dp[j - coin]` 会静默引用表尾，结果全错；
  2. 凑不出的判断是 `dp[amount] > amount`（即 == INF），写成 `if not dp[amount]` 会把 amount = 0 的合法答案 0 误判成 −1；
  3. 哨兵 INF 取 amount + 1 的前提是"严格大于最大合法值"——照搬到别的题前先核对这个前提。
- **面试追问**：
  1. 求**方案数**？→ 累加版（LC 518），组合数必须"硬币在外层"（见②追问一）；
  2. 输出**用了哪些硬币**？→ choice[j] 记录转移来源，从 amount 回溯（见②追问二）。

## 139. 单词拆分

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/word-break/) ｜ 标签：数组 · 字符串 · 动态规划

### ① 题意速览
给定字符串 s 和单词字典 wordDict，判断 s 能否被拆分成一个或多个**字典里的单词**（单词可重复使用、直接拼接）。
- 示例：s = "leetcode"，wordDict = ["leet","code"] → true
- 关键约束：字典单词不重复；同一单词可多次使用；s 与单词均为小写。

### ② 思路讲解
**从暴力出发**：递归尝试"从每个位置切一刀，看切出的前缀是不是词"：canSplit(i) = 存在 j < i 使 canSplit(j) 且 s[j..i−1] 在字典里。递归 + **记忆化**（Memoization，把算过的子问题结果缓存起来）能过，翻成递推更清爽。

**状态定义（说人话）**：dp[i] = **s 的前 i 个字符 s[0:i] 能否被字典拆分**。注意 i 是"前缀长度 / 切分位置"，不是"第几个字符"——与 279/322 的"容量"同一语义家族。

**转移方程（枚举最后一个词）**：dp[i] 为真 ⇔ 存在切分点 j < i，使 dp[j] 为真（前半段 s[0:j] 能拆）**且** s[j:i] 恰好是字典里的词。"盯最后一段词"与打家劫舍"盯最后一家"、零钱兑换"盯最后一枚硬币"是同一个思考动作：**把大问题的最后一步分类，接上子问题的答案**。

**两个工程细节**：字典转 **set**，"s[j:i] 在不在"从线性扫描变 O(1) 哈希；内层 j 只需从 max(0, i − maxLen) 枚举（maxLen 为最长词长），更早的切分点切出的词太长必不可能命中——常数量级的剪枝。

**与完全背包的等价视角**：背包容量 = 前缀长度 i，物品 = 字典词（体积 = 词长、可无限使用），"恰好装满" = 完全拆分——这是完全背包的**可行性判定**版（279/322 问"最少件数"，本题问"能不能"，布尔化而已）。

**初始化与遍历顺序**：dp[0] = true——空串由零个词组成、视为可拆，这是递推的种子（与 dp[0] = 0 一个道理）；i 从 1 到 n，答案 dp[n]。

**不变量**：算 dp[i] 时 dp[0..i−1] 全部就绪；dp[i] 的真假只由已就绪状态与当前词段决定。

**套路迁移**："枚举切分点"家族：131 分割回文串（回溯列出所有切法）、132 分割回文串 II（最少切几刀 = "最少件数"版）、LC 140 单词拆分 II（输出所有方案）。**"字符串能不能拆成字典词"永远先立 dp[i] = 前缀可行性**。

### ③ 注释代码
```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)                 # O(1) 查词
        max_len = max(map(len, words))        # 最长词长：内层枚举的左界剪枝
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True                          # 空串可拆（0 个词）——递推种子
        for i in range(1, n + 1):             # dp[i]：前 i 个字符能否拆分
            # 不变量：dp[0..i-1] 均已就绪
            for j in range(max(0, i - max_len), i):
                # 枚举最后一个词 s[j:i]：前半段可拆 且 这一段是完整单词
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break                     # 找到一个切法即可，剪枝
        return dp[n]
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(n·L²)**（L 为最长词长：每个前缀枚举 ≤ L 个切分点、每次切片 + 哈希查词 O(L)）；**空间 O(n + 字典总长)**。
- **易错点**：
  1. 下标语义错位：dp[i] 是"前 i 个字符"，对应子串 s[j:i]（左闭右开）——把 j 当字符下标用会整体漂移；
  2. dp[0] = true 忘了：所有转移链的源头断了，任何非空 s 都会得 false；
  3. 字典不转 set 直接 `in list`：每次查词 O(词数 × 词长)，数据一大就超时；
  4. s 为空串时答案就是 dp[0] = true，别写返回 false 的兜底。
- **面试追问**：
  1. 输出**所有拆分方案**（LC 140）？→ 先用本题 dp 做可行性剪枝，再在"dp[j] 为真且 s[j:i] 是词"的切分点上 DFS 收集，避免无效搜索；
  2. 和零钱兑换是什么关系？→ 同一副完全背包骨架：词 = 硬币、前缀长度 = 金额、布尔 dp = "能否恰好装满"，连"物品可重复使用"都一致。

## 300. 最长递增子序列

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/longest-increasing-subsequence/) ｜ 标签：数组 · 二分查找 · 动态规划

### ① 题意速览
整数数组里选一个子序列（可跳字、保持原相对顺序），使其**严格递增**，求最长长度。
- 示例：`[10,9,2,5,3,7,101,18]` → 4（2,3,7,101 或 2,3,7,18）
- 关键约束：严格递增（相等不算）；进阶要求给出 O(n log n) 解法。

### ② 思路讲解
**状态定义（说人话，O(n²) 版）**：dp[i] = **以 nums[i] 结尾**的最长递增子序列（LIS，Longest Increasing Subsequence，最长递增子序列）长度。为什么必须钉死"以 i 结尾"？LIS 相邻两个选中元素必须是"前驱—后继"关系，"结尾"就是拼接的接口；只定义"前 i 个里的 LIS"无法转移——新元素接不上一个明确的结尾。

**转移方程**：dp[i] = 1 + max(dp[j])，其中 j < i 且 nums[j] < nums[i]（任何比 nums[i] 小的结尾都能当前驱）；没有合法 j 时 dp[i] = 1（自己单独成序）。答案 = **max(dp)**，不是 dp[n−1]——最优子序列未必以最后一个元素结尾。双层循环 O(n²)。

**进阶 O(n log n)：tails 数组 + 二分**。定义 **tails[k] = 长度为 k+1 的递增子序列中，结尾元素的最小值**。逐个处理元素 x：x 大于 tails 末尾就直接 append（LIS 长度 +1）；否则二分找**第一个 ≥ x** 的位置并**替换**为 x。

**为什么 tails 有序**：归纳论证——若"长度 k 的最小结尾"是 t，那么"长度 k+1 的最小结尾"必然 > t（若 ≤ t，把长度 k+1 的那条截掉末尾，就得到结尾更小的长度 k 序，矛盾）。每步操作都保持该性质，tails 严格递增，二分合法。

**为什么替换不破坏正确性**：替换把"该长度的最小结尾"变得更小，等于**为未来保留更多接续机会**（结尾越小，后面能接的数越多）。tails 的定义只承诺"长度为 k 的递增子序列存在，且最小结尾是 tails[k−1]"，不承诺记住具体哪一条——长度既没变长也没变短，承诺未被破坏，后续每一步仍正确。**注意 tails 不是任何一条真实的 LIS**，它只是"各级长度的最优结尾"档案；答案 = tails 长度。

**追问·打印方案**：在 O(n²) 版转移取 max 时记 pre[i] = argmax（i 的前驱下标），最后从全局 max 对应的 i 沿 pre 回溯倒推即方案；二分版记前驱要额外维护位置栈，面试答 O(n²) 版即可。

**套路迁移**："以 i 结尾"是子序列 DP 的标配状态。家族：LC 673 最长递增子序列的个数（dp 外再挂一个方案计数）、LC 376 摆动序列（上升/下降交替 → 两个状态）、LC 354 俄罗斯套娃信封（二维 LIS：按宽排序后对高跑 LIS）。心法：**维护"每个长度的最优结尾"，让它有序以便二分**。

### ③ 注释代码
```python
from bisect import bisect_left

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        # O(n log n)：tails[k] = 长度为 k+1 的递增子序列的最小结尾
        tails: List[int] = []
        for x in nums:
            # 不变量：tails 严格递增，tails[k] 始终是"长度 k+1 的最小结尾"
            i = bisect_left(tails, x)   # 第一个 >= x 的位置（严格递增用 left）
            if i == len(tails):
                tails.append(x)         # x 比所有结尾都大：LIS 变长
            else:
                tails[i] = x            # 替换：同长度换更小结尾，为未来留接续机会
        return len(tails)
```
> O(n²) 基础版（面试先讲它更顺）：`dp = [1] * n`；对每对 `j < i` 且 `nums[j] < nums[i]` 执行 `dp[i] = max(dp[i], dp[j] + 1)`；答案为 `max(dp)`（不是 `dp[-1]`）。

### ④ 复杂度 · 易错点 · 面试追问
- **O(n²) 版**：时间 O(n²)、空间 O(n)；**二分版**：时间 O(n log n)、空间 O(n)。
- **易错点**：
  1. O(n²) 版答案是 `max(dp)` 而不是 `dp[-1]`；
  2. **严格**递增用 `bisect_left`（相等元素也被替换掉）；若题意允许相等（非严格递增）才用 `bisect_right`——两处反着写答案就错；
  3. 别把 tails 当成某条真实的 LIS 去输出或检查——它只是各级"最小结尾"的档案；
  4. 二分版长度只由 append 推进，替换只发生在中间位置——理解错这点会把"替换"误当"增长"。
- **面试追问**：
  1. 输出具体子序列？→ O(n²) 版记 pre 前驱回溯（见②追问）；
  2. 二维版（LC 354 信封嵌套）？→ 按宽升序、**宽相同按高降序**排序，再对高跑本题——降序防止同宽信封互相套入。

## 152. 乘积最大子数组

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/maximum-product-subarray/) ｜ 标签：数组 · 动态规划

### ① 题意速览
整数数组（可含负数与 0）里找**连续**子数组，使其乘积最大，返回最大乘积。
- 示例：`[2,3,-2,4]` → 6（子数组 [2,3]）；`[-2,0,-1]` → 0
- 关键约束：子数组必须连续；答案保证在 32 位整数内。

### ② 思路讲解
**53 题的套路为什么失效**：53 题（最大子数组和）只维护"以 i 结尾的最大和"一个状态就够——加法世界里"大 + 正数 = 更大"，极值只会在最大值一端。乘法世界多了个反派：**负数乘负数会翻身**——当前最小的（最负的）数乘上一个负数，可能一跃成为最大。只盯着最大值，就会漏掉"最小值 × 负数"这条逆袭线。

**状态定义（说人话）**：同时养两个状态——curMax[i] = 以 i 结尾的子数组的**最大**乘积，curMin[i] = 以 i 结尾的子数组的**最小**乘积。curMin 不是副产品，是为"将来遇到负数"埋的伏笔。

**转移方程**：以 i 结尾的子数组要么从 nums[i] 自己开始，要么接在以 i−1 结尾的某段后面。候选三个：
1. nums[i] 本身——前面的段乘积是 0 或烂透了时，"另起炉灶"是唯一生路；
2. curMax[i−1] × nums[i]——顺着最大续；
3. curMin[i−1] × nums[i]——负负得正地翻身。
curMax[i] = max(三者)，curMin[i] = min(三者)。**不必按 nums[i] 的正负写分支**：三个候选同时喂给 max 和 min，四种正负情形被对称地吸收掉。

**遍历与答案**：i 从 1 滚到 n−1；答案 = 每一步 curMax 的最大值——最优子数组可以结束在**任何**位置，不是最后一步。

**不变量**：处理到 i 时，curMax/curMin 恰是"以 i−1 结尾"的全局最大/最小乘积——乘法的极值只会出现在这两个端点（乘正数保序、乘负数翻转、乘 0 归零，都由原端点决定），两个状态合起来无遗漏。

**套路迁移**："一个状态不够就拆成两个"的样板：53 题（和、单状态）、本题（积、双状态）、LC 918 环形子数组的最大和（最大和 + 最小和 + 总和三件套）。口诀：**转移存在"翻转"（负负得正、取反）时，把最值两端都养起来**。

### ③ 注释代码
```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        curMax = curMin = ans = nums[0]   # 以 0 号结尾的最大/最小/全局最优
        for x in nums[1:]:
            # 不变量：curMax/curMin 是"以上一个元素结尾"的最大/最小乘积
            # 三个候选：x 单开；接在最大后面；接在最小后面（负负翻身）
            cands = (x, curMax * x, curMin * x)
            curMax, curMin = max(cands), min(cands)   # 两状态必须同步更新
            ans = max(ans, curMax)        # 最优子数组可结束于任何位置
        return ans
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(n)**：一遍扫描；**空间 O(1)**：滚动变量。
- **易错点**：
  1. 只维护 curMax 不维护 curMin：`[-2,3,-4]` 会得 3（漏掉 (−2)×3×(−4) = 24）；
  2. curMax 和 curMin 要**同步更新**（先算好候选再一起赋值）——先更新 curMax 再用新值更新 curMin 就串轮了；
  3. ans 要在循环里每步取 max：`[2,3,-2,4]` 结尾处 curMax = 4，只看最后一步会漏掉 6；
  4. x = 0 的轮次三个候选天然把它处理掉（都是 0 或更小），不必特判。
- **面试追问**：
  1. 输出**子数组的起止位置**？→ curMax 的候选是"接在后面"时起点沿用上一步、是"x 单开"时起点重置为 i，同步记录即可；
  2. 什么时候和 53 题等价？→ 数组全为非负时"负负翻身"线消失，退化为单状态——能讲出"状态数量由转移的对称破缺决定"是加分项。

## 416. 分割等和子集

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/partition-equal-subset-sum/) ｜ 标签：数组 · 动态规划

### ① 题意速览
非空正整数数组能否被**划分成两个子集**，使两个子集的元素和相等。
- 示例：`[1,5,11,5]` → true（[1,5,5] 与 [11]）；`[1,2,3,5]` → false
- 关键约束：每个元素只能进其中一个子集（每件用一次）；元素均为正。

### ② 思路讲解
**问题转化（本题第一难关）**：两个子集和相等 ⇔ 每个子集都等于 **sum / 2** ⇔ 能否选出若干数字**恰好凑出 sum/2**。于是变成 **01 背包**（0/1 Knapsack，每件物品至多用一次）的**可行性判定**：容量 target = sum/2，物品 = 数字（体积 = 数值），问"能否恰好装满"——注意与 279/322 的"无限使用"划清界限：这里每个数字只有一件。

**两步剪枝**：sum 为**奇数**直接 false（没法均分）；max(nums) > target 直接 false（最大的数塞哪边都爆）。

**状态定义（说人话）**：dp[j] = 用已考虑过的若干数字，能否恰好凑出和 j。**转移方程**：来一个数字 x，dp[j] = dp[j] or dp[j − x]——x 不用（维持原状）或用（j − x 可达则 j 可达）。**初始化**：dp[0] = true（什么都不选凑出 0）。**遍历顺序是本题的灵魂**：外层物品、内层容量**倒序**（j 从 target 到 x）。

**为什么必须倒序（讲透"防重复选取"）**：一维滚动时 dp[j − x] 想要的是"**还没考虑 x**"时的旧值。**正序**遍历时 dp[j − x] 可能刚在本轮被 x 更新过——同一件 x 被连用两次，那正是**完全背包**的语义；**倒序**时 dp[j − x] 还没被本轮触碰，必然是旧值，每件物品至多选一次。一句话：**01 背包倒序、完全背包正序——遍历方向就是"每件物品选一次还是无限次"的开关**。

**不变量**：外层处理完前 i 件物品后，dp[j] = "前 i 件中能否选出和恰好为 j"。

**套路迁移**：01 背包判定版。家族：LC 494 目标和（正负号分配 ⇔ 选出子集凑 (sum+target)/2）、LC 1049 最后一块石头的重量 II（把石头分两堆尽量接近 = 本题的 min 版）。口诀：**"分成两份 / 凑出指定和" → 总和折半 + 01 背包可达性**。

### ③ 注释代码
```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:                 # 奇数和必不能均分
            return False
        target = total // 2
        if max(nums) > target:        # 最大数单边都放不下
            return False
        dp = [False] * (target + 1)
        dp[0] = True                  # 不选任何数 -> 和为 0 可达
        for x in nums:                # 外层：物品，每件至多用一次
            for j in range(target, x - 1, -1):   # 内层：容量【倒序】防同一件选两次
                # 不变量：到达 j 时 dp[j-x] 还是"未考虑 x"的旧值
                dp[j] = dp[j] or dp[j - x]
            if dp[target]:            # 提前收工（剪枝）
                return True
        return dp[target]
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(n × target)**；**空间 O(target)**。
- **易错点**：
  1. 容量循环写成**正序**：变成完全背包，`[1,2]`、target = 2 会因 1 被用两次而误判 true；
  2. `range(target, x - 1, -1)` 的下界是 x − 1：写漏会让 j < x 时 `dp[j - x]` 引用负下标（Python 静默出错）；
  3. 忘了 dp[0] = true：所有转移链的源头断了；
  4. 奇数和、max > target 的剪枝不做也能对，但大数组上白跑一倍。
- **面试追问**：
  1. 若要求**输出两个子集**？→ 一维滚动丢了轮次信息，请退回二维 dp 或记录"选/不选"路径，从 (n, target) 回溯；
  2. 元素有负数怎么办？→ 可行域整体平移（和的范围 [负和, 正和]），dp 下标加偏移量即可，骨架不变。

## 32. 最长有效括号

> [难度：困难] ｜ [LeetCode 链接](https://leetcode.cn/problems/longest-valid-parentheses/) ｜ 标签：栈 · 数组 · 动态规划 · 字符串

### ① 题意速览
只含 '(' 和 ')' 的字符串，求最长**连续**且格式合法（每对左右括号正确闭合）的子串长度。
- 示例：s = "(()" → 2（"()"）；s = ")()())" → 4（"()()"）
- 关键约束：子串必须连续；s 可为空。

### ② 思路讲解
**从暴力出发**：枚举每个子串验合法性 O(n³)，不可行。先抓结构：合法子串以 ')' 收尾，而**一个 ')' 要么立刻匹配掉一个 '('，要么自己作废并把两侧合法段隔开**。

**主线·栈版（推荐）**：栈里放**下标**而不是字符，并且**栈底永远垫着"最后一个未匹配位置"当分界碑**——初始化压入哨兵 −1。逐字符扫描：
- 遇 '('：下标入栈待匹配；
- 遇 ')'：先 pop——
  - 弹空了：这个 ')' 自己 unmatched，把它的下标**压栈当新分界碑**；
  - 弹出了一个 '('：当前以 i 结尾的有效段 = 从"新栈顶 + 1"到 i，长度 `i − stack[-1]`——**新栈顶正是上一个未匹配位置**，有效段不可能跨越它。

**不变量**：任何时刻"栈顶"之后到当前扫描位置之间没有未匹配的坏点；于是 ')' 弹出成功时 `i − stack[-1]` 就是"以 i 结尾的最长有效长度"，逐位更新 ans。每个下标至多一次入栈一次出栈，O(n) 一遍过。哨兵 −1 让"从头开始的合法段"也有基准可减（如 s = "()" 的 i = 1：i − (−1) = 2）。

**简述·dp 版（应对"不用栈"的追问）**：状态定义（说人话）：dp[i] = **以 i 结尾**的最长有效括号长度（s[i] 为 '(' 时 dp[i] = 0）。i 为 ')' 时分两支：
- s[i−1] == '('：形如 "…()"，dp[i] = dp[i−2] + 2；
- s[i−1] == ')'：形如 "…))"，若 s[i − dp[i−1] − 1] == '('，则 dp[i] = dp[i−1] + 2 + dp[i − dp[i−1] − 2]（内部整段 + 这一对 + 更前面接上的整段）。
分支多、边界碎，面试先交栈版，dp 版备作加分讨论。

**套路迁移**：括号家族通吃两条路——栈存**下标**（LC 20、678 有效括号/带通配符）与"以 i 结尾"DP。分界碑思想与接雨水的 leftMax 同气：**算长度/水量这类"减法"时，必须有一个"最近的障碍"当减数**。

### ③ 注释代码
```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        ans = 0
        stack = [-1]          # 哨兵：最后一个"未匹配位置"，初始 -1（虚拟分界碑）
        for i, ch in enumerate(s):
            if ch == '(':
                stack.append(i)       # 待匹配：下标入栈
            else:
                stack.pop()           # 先弹：消耗一个 '(' 或弹掉旧分界碑
                if not stack:
                    stack.append(i)   # 弹空：这个 ')' unmatched -> 新分界碑
                else:
                    # 不变量：stack[-1] 是最后一个未匹配位置，其后到 i 全程有效
                    ans = max(ans, i - stack[-1])
        return ans
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(n)**：每个下标至多进出栈各一次；**空间 O(n)**：栈。
- **易错点**：
  1. 哨兵 −1 忘压：`i − stack[-1]` 的基准与"弹空"判断全乱；
  2. 遇 ')' 必须**先 pop 再判空**——顺序反了弹空分支永远走不到；
  3. 长度是 `i − stack[-1]`，**不加 1**：分界碑位置本身不属于有效段（它是未匹配的 ')' 或虚拟 −1）；
  4. dp 版的 `i − dp[i-1] − 1` 可能为负，先判 `i − dp[i-1] > 0` 再取字符。
- **面试追问**：
  1. O(1) 空间可行吗？→ 两遍扫描计数器法：正扫记左右括号数，相等结算、右多于左就清零；再反扫对称处理（正扫漏掉的 "(()" 靠反扫捡回）；
  2. 括号带 `*` 通配符（LC 678）？→ 维护"未匹配 '(' 数量的可能区间 [lo, hi]"，扫完看 lo 是否为 0——把确定性计数改成区间传播。

## 62. 不同路径

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/unique-paths/) ｜ 标签：数学 · 动态规划 · 组合数学

### ① 题意速览
m × n 网格，机器人从**左上角**出发，每步只能**向右或向下**，走到右下角，问有多少条不同路径。
- 示例：m = 3, n = 7 → 28
- 关键约束：只许右/下两个方向；1 ≤ m, n ≤ 100。

### ② 思路讲解
**状态定义（说人话）**：f(i, j) = 从起点 (0,0) 走到格子 (i, j) 的路径条数。**转移方程**：最后一步要么从上面 (i−1, j) 下来、要么从左边 (i, j−1) 右移——两条来路互斥且穷尽：f(i, j) = f(i−1, j) + f(i, j−1)。这就是把 118 杨辉三角"上一行两数相加"平移到网格上：**同一个递推，换了张地图**——"多维动态规划"专题的新意也仅止于此。

**初始化与遍历顺序**：第一行、第一列全为 1（只能一路直走，路径唯一）；i、j 从 1 起按行填表，每个格子的上、左依赖均已就绪——二维表"从左上到右下"的遍历天然满足依赖方向。

**一维滚动优化**：逐行填表时 f(i, j) 只需要两样：上一行同列（更新前的 dp[j]）与本行左邻（更新后的 dp[j−1]）——于是 `dp[j] += dp[j-1]` 一行搞定，空间 O(mn) → O(n)。**"更新前的自己是上一行、更新后的左邻是本行"是一维滚动的通用读法**。

**追问·组合数公式 O(min(m, n))**：一条路径由 (m−1) 个"下"和 (n−1) 个"右"排成一列，路径数 = 从 m+n−2 步里选 m−1 步走"下" = **C(m+n−2, m−1)**（杨辉三角里的那个数，见 118 追问）。用 `math.comb` 一行或边乘边除手算，比 DP 的 O(mn) 少一个维度——面试先写 DP 拿稳，再甩组合数收官。

**不变量**：处理完第 i 行后，dp[j] = f(i, j) 对所有 j 成立。

**套路迁移**：网格路径计数原型。家族：不同路径 II（LC 63，障碍格 f = 0 即可）、64 最小路径和（同骨架换 min）、LC 931 下降路径最小和（三个来源）。**网格 DP 起手式：只许右/下 → 转移只有上、左两个来源**。

### ③ 注释代码
```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [1] * n            # 第 0 行全 1：只能一路向右
        for _ in range(1, m):           # 逐行向下
            for j in range(1, n):
                # 更新前 dp[j] = 上一行同列（从上来），dp[j-1] = 本行左邻（从左来）
                dp[j] += dp[j - 1]
            # 不变量：处理完第 i 行后 dp[j] = f(i, j)
        return dp[n - 1]
```

### ④ 复杂度 · 易错点 · 面试追问
- **DP**：时间 O(mn)、空间 O(n)；**组合数**：时间 O(min(m, n))、空间 O(1)。
- **易错点**：
  1. 一维滚动里 `dp[j] += dp[j-1]` 的 j 必须从 1 开始——dp[0] 每行恒为 1，别在内层动它；
  2. 双层循环行列写反：外层行数 m、内层列数 n，数组按"一行 n 个"开；
  3. 手写组合数时先算阶乘再相除会溢出——要边乘边除（或直接用 `math.comb`）。
- **面试追问**：
  1. 网格里有**障碍物**（LC 63）？→ 障碍格 f(i, j) = 0，其余照旧；第一行/列遇到障碍后整段置 0；
  2. 允许四个方向自由走、求路径数？→ 递推不再无环，得用图论（DFS/BFS 或矩阵快速幂）——能点破"DP 的适用前提是无环 + 无后效性"是加分项。

## 64. 最小路径和

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/minimum-path-sum/) ｜ 标签：数组 · 动态规划 · 矩阵

### ① 题意速览
m × n 非负整数网格，从左上角走到右下角，每步只能右或下，使路径上数字之和最小，返回该最小和。
- 示例：`[[1,3,1],[1,5,1],[4,2,1]]` → 7（1→3→1→1→1）
- 关键约束：只许右/下；grid 元素非负。

### ② 思路讲解
**与 62 同骨架、加法变 min**：状态定义（说人话）：f(i, j) = 从 (0,0) 走到 (i, j) 的路径数字和的最小值。**转移方程**：f(i, j) = grid[i][j] + min(f(i−1, j), f(i, j−1))——来路仍是上、左两条，把"计数累加"换成"取小再累计"。

**为什么第一行/第一列是前缀和**：第一行只能一路向右——到 (0, j) 的路径**唯一**，最小和就是 grid[0][0..j] 的累加；第一列同理向下累加。初始化不是拍脑袋填 0，而是"路径唯一 ⇒ 前缀和"推出来的——**DP 的每一条初始化都该能说出理由**（62 题首行首列全 1 是同一句话的另一面：路径唯一 ⇒ 条数 1）。

**一维滚动**：dp[j] = min(dp[j], dp[j−1]) + grid[i][j]——更新前 dp[j] 是上一行（从上来）、更新后 dp[j−1] 是本行（从左来）；第 0 列每行要先 `dp[0] += grid[i][0]` 维护"向下累加"的起点。

**不变量**：滚动处理完第 i 行后，dp[j] = f(i, j)。

**为什么不能贪心**：每步选较小的邻格会被局部陷阱带偏（小格子后面可能接着大坑），而"前缀路径最优 ⇒ 全局最优"的最优子结构 + 只有两个来路的无后效性，正是 DP 的舒适区。

**套路迁移**：网格最值版 = 62 的孪生兄弟。家族：LC 63（障碍 + 计数）、LC 931 下降路径最小和（三来源 min）、LC 120 三角形最小路径和（自底向上更顺）。**网格 DP 先画"来路箭头"，有几个箭头就写几项 min/Σ**。

### ③ 注释代码
```python
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [0] * n
        dp[0] = grid[0][0]
        for j in range(1, n):           # 第 0 行：只能一路向右 -> 前缀和
            dp[j] = dp[j - 1] + grid[0][j]
        for i in range(1, m):           # 逐行向下滚动
            dp[0] += grid[i][0]         # 第 0 列：只能一路向下 -> 前缀和
            for j in range(1, n):
                # 更新前 dp[j] = f(i-1, j)（从上来），dp[j-1] = f(i, j-1)（从左来）
                dp[j] = min(dp[j], dp[j - 1]) + grid[i][j]
            # 不变量：处理完第 i 行后 dp[j] = f(i, j)
        return dp[n - 1]
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(mn)**；**空间 O(n)**（滚动；原地改 grid 可到 O(1) 但污染输入）。
- **易错点**：
  1. 第一列的滚动 `dp[0] += grid[i][0]` 别漏——它是每行滚动的新起点；
  2. 初始化照抄 62 的"全 1"会全错：最值版首行首列必须是**前缀和**；
  3. `min(dp[j], dp[j-1]) + grid[i][j]`：先取小再累计当前格，别写成先累计再取小。
- **面试追问**：
  1. 允许上下左右四个方向？→ 出现环路，DP 的无后效性被打破，变成图上最短路（Dijkstra）——一句话点出 DP 与最短路的分界；
  2. 输出**路径本身**？→ 用二维 dp + 回溯：从终点起每步比较上/左哪边更小就往哪走，倒序还原。

## 5. 最长回文子串

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/longest-palindromic-substring/) ｜ 标签：字符串 · 动态规划

### ① 题意速览
在字符串 s 中找出**最长回文子串**（正读反读相同的连续子串），返回其中之一。
- 示例：s = "babad" → "bab"（"aba" 也对）；s = "cbbd" → "bb"
- 关键约束：子串必须连续；长度 ≥ 1；答案不唯一时任取。

### ② 思路讲解
**主线·中心扩展（推荐）**。观察：回文必以某个"中心"对称——奇数长度的中心是一个字符（n 个），偶数长度的中心是相邻两字符的缝隙（n−1 个），合计 **2n−1 个中心**。逐个中心向两侧同步扩展（两侧字符相等才继续），记录扩出的最长区间。单中心最坏 O(n)，总 **O(n²) 时间、O(1) 空间**——好写好讲常数小，本题性价比之王。

**对比·区间 DP（好想但费空间）**：状态定义（说人话）：f(i, j) = 子串 s[i..j] 是否回文。**转移方程**：f(i, j) = (s[i] == s[j]) 且 f(i+1, j−1)——大区间的真假由**短一层**的子区间决定，所以必须**按子串长度从小到大**填表（长度 1 全 true，长度 2 只看两字符）。结论可靠，但 O(n²) 时间之外还要 O(n²) 布尔空间——面试用它讲"区间 DP 按长度遍历"的思想，实战选中心扩展。

**追问·Manacher（马拉车）算法 O(n) 只讲思路**：两板斧——① 插入分隔符（如 '#'）把奇偶回文统一成奇长度（"abba" → "#a#b#b#a#"）；② 维护当前"右伸最远的回文"的中心 C 与右边界 R，处理新位置 i 时若 i < R，就从 i 关于 C 的**镜像位置**复制已知回文半径作起点（对称性白送一段免算），再从那里尝试向外扩。R 只增不减，总扩展 O(n)。记住"**对称性复用 + 右边界单调不回退**"两个关键词即可，细节公式面试前再背。

**套路迁移**：回文三件套——中心扩展（本题、LC 647 回文子串计数）、区间 DP（LC 516 最长回文**子序列**：子序列可跳字，必须区间 DP）、Manacher（只要长度时的 O(n) 捷径）。心法：**子串问中心、子序列问区间**。

### ③ 注释代码
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expand(l: int, r: int) -> tuple:
            # 从 [l, r] 向两侧同步扩展；返回最终回文的 (l, r)
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            return l + 1, r - 1   # 越界/失配回退一步 = 上一个合法回文区间

        best_l, best_r = 0, 0
        for i in range(len(s)):
            # 不变量：2n-1 个中心（奇数字符 + 偶数缝隙）全部被枚举
            for l, r in ((i, i), (i, i + 1)):   # 奇数长度中心 / 偶数长度缝隙
                l, r = expand(l, r)
                if r - l > best_r - best_l:
                    best_l, best_r = l, r
        return s[best_l:best_r + 1]
```

### ④ 复杂度 · 易错点 · 面试追问
- **中心扩展**：时间 O(n²)、空间 O(1)；**区间 DP**：时间 O(n²)、空间 O(n²)；**Manacher**：时间 O(n)、空间 O(n)。
- **易错点**：
  1. expand 退出时 l、r 已越界/失配，必须返回 (l+1, r−1) 回退一步才是合法回文区间；
  2. 偶数中心 (i, i+1) 在 i = n−1 时 r 越界——while 条件 `r < len(s)` 先判，天然安全，别先取 s[r]；
  3. 区间 DP 必须按**长度**做外层循环，按 i 从小到大会在 f(i+1, j−1) 未算好时引用它；
  4. "aaaa" 这类偶回文只有偶数中心能拿满，两类中心都要枚举。
- **面试追问**：
  1. 求**回文子串个数**？→ 每个中心每扩成功一层计 1（LC 647），复杂度不变；
  2. 最长回文**子序列**（LC 516）？→ 区间 DP：相等 f(i+1, j−1) + 2，否则 max(f(i+1, j), f(i, j−1))——允许跳字，中心扩展失效。

## 1143. 最长公共子序列

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/longest-common-subsequence/) ｜ 标签：字符串 · 动态规划

### ① 题意速览
给定两个字符串 text1、text2，求它们最长公共子序列（LCS，Longest Common Subsequence，最长公共子序列）的长度；子序列可跳字但保持相对顺序。
- 示例：text1 = "abcde"，text2 = "ace" → 3（"ace"）
- 关键约束：子序列不要求连续；无公共子序列返回 0。

### ② 思路讲解
**为什么必须二维**：局面有两个自由度——比到 a 的第几个字符、比到 b 的第几个字符，一个下标装不下。"多维动态规划"的第一课：**自由度几维，状态就开几维下标**（这里的多维就是两个字符串游标组成的 (i, j)）。

**状态定义（说人话）**：dp[i][j] = a 的前 i 个字符与 b 的前 j 个字符的 LCS 长度。**转移方程**盯**末字符** a[i−1] 与 b[j−1]：
- 相等：这个公共字符**白拿**——接在"双双去掉末字符"的答案后：dp[i][j] = dp[i−1][j−1] + 1；
- 不等：公共子序列的结尾至少要弃掉 a[i−1] 或 b[j−1] 之一：dp[i][j] = max(dp[i−1][j], dp[i][j−1])（"删 a 末"或"删 b 末"取优）。

**为什么相等时不必再 max**：可证 dp[i−1][j] ≤ dp[i−1][j−1] + 1、dp[i][j−1] ≤ dp[i−1][j−1] + 1，"白拿"一项已不劣于任何候选——转移因此只剩一项。**"子序列可以跳字"正是不等时仍有退路的原因**：丢掉一个末字符，解的可达性不丢。

**初始化与遍历顺序**：dp[0][j] = dp[i][0] = 0（空串与任何串的 LCS 为 0）——多开一行一列、第 0 行/列当空串，i、j 从 1 起双层递增，上/左/斜上三个依赖均就绪；答案 dp[m][n]。**下标偏移是二维字符串 DP 的标配**。

**对比"连续"版（LC 718 最长重复子数组）**：问的是最长公共**子数组**（连续），失配就没有退路：f(i, j) = f(i−1, j−1) + 1（相等）**否则 0**，答案取全表 max 而非右下角。记忆：**可跳字 → 失配仍取 max(删 a, 删 b) 续命；必须连续 → 失配清零重来**——一字之差，转移两副面孔。

**追问·输出方案**：填表时记来源方向（斜上/上/左），从 dp[m][n] 回溯到边界，每走一步"斜上"就把 a[i−1] 收进 LCS，最后倒序输出。

**套路迁移**：双字符串 DP 原型。家族：72 编辑距离（同一张表、三个来源）、LC 583 两个字符串的删除操作（只许删除 ⇔ m + n − 2×LCS）、LC 97 交错字符串。起手式：**两个游标 + "末字符比不比得上"分类**。

### ③ 注释代码
```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        # dp[i][j]：a 前 i 个字符 与 b 前 j 个字符 的 LCS 长度
        # 多开一行一列，dp[0][*] = dp[*][0] = 0 表示空串
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 不变量：dp[i-1][j-1]、dp[i-1][j]、dp[i][j-1] 均已就绪
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1     # 末字符相等：白拿
                else:
                    # 末字符至少弃一个：删 a 末 / 删 b 末，取优
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(mn)**；**空间 O(mn)**（滚动两行可降到 O(min(m, n))）。
- **易错点**：
  1. 下标偏移最易翻车：状态是"前 i 个字符"，字符是 text1[i−1]——错一位答案整体漂移；
  2. 二维表别写成 `[[0] * (n + 1)] * (m + 1)`——浅拷贝让所有行共享同一块内存；
  3. 相等分支别再套 max（不致错但说明没想透"白拿"的论证）；
  4. 单行滚动优化时相等分支需要 dp[i−1][j−1]，要用临时变量在覆盖前保存斜上旧值。
- **面试追问**：
  1. 输出具体 LCS？→ 记来源方向或直接从 dp 表回溯（见②追问），O(m + n) 步；
  2. 三个字符串的 LCS？→ 状态升到 dp[i][j][k]，转移枚举末字符是否相等——"自由度几维、状态几维"的直接推广（顺带说出 O(n³) 的维度爆炸代价意识）。

## 72. 编辑距离

> [难度：中等] ｜ [LeetCode 链接](https://leetcode.cn/problems/edit-distance/) ｜ 标签：字符串 · 动态规划

### ① 题意速览
给定两个单词 word1、word2，允许**插入、删除、替换**一个字符三种操作，求把 word1 变成 word2 所需的**最少操作次数**。
- 示例：word1 = "horse"，word2 = "ros" → 3（替换 h→r、删 r、删 e：horse→rorse→rose→ros）
- 关键约束：三种操作各算 1 步；两串可为空（此时答案 = 另一串长度）。

### ② 思路讲解
**状态定义（说人话）**：dp[i][j] = 把 a 的**前 i 个字符**变成 b 的**前 j 个字符**的最少操作数。与 1143 同一张双游标二维表，问法从"最长公共"换成"最少操作"。

**转移方程——三种操作对应三个来源**：盯末字符 a[i−1] 与 b[j−1]：
- **相等**：末字符无需动，白拿：dp[i][j] = dp[i−1][j−1]；
- **不等**，最后一步三选一（取最小）：
  - **替换** a[i−1] → b[j−1]：前 i−1 对前 j−1 已变好 → dp[i−1][j−1] + 1；
  - **删除** a[i−1]：前 i−1 个已能变成 b 前 j 个 → dp[i−1][j] + 1；
  - **插入**（a 末尾插 b[j−1]）：a 前 i 个已能变成 b 前 j−1 个 → dp[i][j−1] + 1。

**"对 a 插入 ≡ 对 b 删除"，三来源互恰不多不少**：给 a 插入一个字符使其变成 b，换到 b 的视角看，等价于把 b 的末字符删掉再对齐——"插入"这个操作天然由 dp[i][j−1] 承接，不需要第六个方向。替换 / 删 a / 删 b（即插 a）恰好一一对应斜上、上、左三个格子——**这就是编辑距离恰好三个来源的代数原因**，多加少加一项都说明概念没吃透。

**初始化**：dp[i][0] = i（a 前 i 个全删成空串）；dp[0][j] = j（空串全插出 b 前 j 个）。空串情形必须显式作答，它们是 i = 1 / j = 1 转移的地基。

**遍历顺序**：i、j 从小到大，斜上/上/左三个依赖就绪；答案 dp[m][n]。

**追问·输出具体操作序列**：从 dp[m][n] 回溯：末字符相等走斜上（此步无操作）；否则找哪个来源恰好等于 dp[i][j] − 1，走到哪记下对应操作（替换 / 删除 a[i−1] / 在 a 末插入 b[j−1]），触边即止，共 O(m + n) 步。

**套路迁移**：双字符串 DP 收官：1143 是"白拿 + 二选一"，本题是"白拿 + 三选一"。家族：LC 583（只许删除的两步版）、LC 712 ASCII 删除最小和（把次数换成 ASCII 权重）、LC 10/44 正则与通配符匹配（带模式符的特判转移）。心法：**状态 = 两个前缀，转移 = 末字符"相干 / 不相干"分类**。

### ③ 注释代码
```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        # dp[i][j]：a 前 i 个字符 -> b 前 j 个字符 的最少操作数
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            dp[i][0] = i        # 全删成空串
        for j in range(1, n + 1):
            dp[0][j] = j        # 空串全插出来
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 不变量：斜上/上/左三个依赖均已就绪
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]      # 末字符相等：白拿，0 操作
                else:
                    # 三来源：替换（斜上）/ 删 a（上）/ 插 a 即删 b（左）
                    dp[i][j] = 1 + min(dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]
```

### ④ 复杂度 · 易错点 · 面试追问
- **时间 O(mn)**；**空间 O(mn)**（两行滚动可降到 O(min(m, n))）。
- **易错点**：
  1. 边界 dp[i][0] = i、dp[0][j] = j 写成 0：递推地基塌了，小样例 "a" → "ab" 就暴露；
  2. 相等分支错写成 dp[i−1][j−1] + 1（多算一次操作），或不等分支漏掉某个来源；
  3. 觉得"插入"还需要额外一项？三个来源已互恰覆盖（插 a ≡ 删 b），多加项恰恰说明概念不清；
  4. 滚动数组优化时 dp[i−1][j−1] 要用临时变量在覆盖前保存。
- **面试追问**：
  1. 输出**操作序列**？→ 从 dp[m][n] 回溯来源（见②追问），每格 O(1) 判定，总 O(m + n) 步；
  2. 只允许**删除**怎么改（LC 583）？→ 相等白拿不变，不等只剩 max(删 a, 删 b) 两个来源；答案也 = m + n − 2×LCS，正好验证与 1143 的内在联系。
